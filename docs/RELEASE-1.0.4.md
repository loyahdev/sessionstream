# SessionStream 1.0.4

- DAW-to-DAW sending requires SessionStream Pro. Collaborators can receive and record from an updated Pro sender for free. A host can still require a passcode, approval, or a verified listener account.
- SessionStream Pro with Cloud streaming supports classes of 100+ students. Cloud usage depends on attendance, stream duration, and audio format.
- The plugin selects the account's saved custom link on load and shows progress while the engine starts, the account signs in, or the link loads.
- Slow session commands keep the local streaming helper alive while the plugin waits for a response.

Close your DAW before updating. The macOS installer includes Apple Silicon VST3 and AU. The Windows installer includes x64 and ARM64 VST3 for Windows 11.
